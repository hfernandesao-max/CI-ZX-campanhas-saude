# ci-zx-campanhas-saude

Materiais das campanhas de saúde da ConsultIT e da Zentrix, publicados com GitHub Pages.

## Estrutura

```
index.html                  Página inicial com a lista de campanhas
assets/                     Selo do grupo e laço
outubro-rosa-2026/
  quiz.html                 Quiz «Mito ou Verdade?» (12 perguntas, para projectar)
  video.mp4                 Vídeo de sensibilização
```

## Publicar

Settings → Pages → Source: *Deploy from a branch* → ramo `main`, pasta `/ (root)` → Save.

Ligações:
- Página inicial: `https://<utilizador>.github.io/ci-zx-campanhas-saude/`
- Quiz: `https://<utilizador>.github.io/ci-zx-campanhas-saude/outubro-rosa-2026/quiz.html`

## Nova campanha

Criar uma pasta nova (por exemplo `novembro-azul-2026/`) e acrescentar um cartão em `index.html`.
